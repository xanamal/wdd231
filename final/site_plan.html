Siege Study Site Plan

Rainbow Six Siege Ranked Map Callout Guide

```

Site Name

Siege Study

This name was selected because the website is focused on helping Rainbow Six Siege players study ranked maps, learn callouts, and become better teammates during matches.

Optional domain idea: siegestudy.com

Site Purpose

The purpose of Siege Study is to provide a simple map study guide for Rainbow Six Siege players. The site will show selected ranked maps, basic map layouts, important callouts, and helpful information for players who want to improve their ranked communication.

This project will include five maps instead of every ranked map so the website stays realistic for a first-year web development project.

Scenarios

  • What are the main callouts I should know before playing a ranked match?
  • Where can I view a simple layout for one of the selected Rainbow Six Siege maps?
  • How can I suggest a new map or report a mistake on the site?

Color Scheme

The color palette is based on a dark tactical theme while avoiding Ubisoft's red and black branding.

  • Primary Background: Dark Navy - #0F172A - Used for the page background.
  • Secondary Background: Slate Blue - #1E293B - Used for sections, header, and footer.
  • Accent Color: Tactical Teal - #14B8A6 - Used for buttons, highlights, and important details.
  • Highlight: Sky Blue - #38BDF8 - Used for headings.
  • Light Text: Off White - #F8FAFC - Used for body text.
  • Borders: Steel Gray - #475569 - Used for section borders and card outlines.

Typography

  • Arial - Used for body text, headings, navigation, and form labels.

Arial was chosen because it is simple, readable, and easy to use for a beginner web development project.

Website Pages

Home Page

The home page will introduce the site, show a short description, display five featured maps, and include a small updates or news section.

About Us Page

The About Us page will explain why the site was created and include a short personal story about my ranked experience and why callouts are important.

Maps Page

The Maps page will show five clickable map cards: Bank, Club House, Chalet, Oregon, and Kafe Dostoyevsky. When a user selects a map, they will see a larger schematic and callout list.

Contact Page

The Contact page will include a form where visitors can send map ideas, corrections, or feature suggestions.
```
